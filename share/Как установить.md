# TrackTasks — как установить

Трекер задач по папкам с проектами (задачи — .md-файлы в `<проект>/tasks/`) + личные задачи из Напоминаний + Claude Code внутри.

**Нужно:** macOS 26 или новее.

## Установка

1. Распакуй архив и перетащи **TrackTasks.app** в «Программы».
2. Открой его двойным кликом. macOS скажет, что разработчик не проверен, — это нормально: приложение собрано вручную, не из App Store.
3. Открой «Системные настройки» → «Конфиденциальность и безопасность», пролистай вниз и нажми **«Всё равно открыть»** у TrackTasks. Подтверди паролем.

Если кнопки нет — в Терминале:
```
xattr -dr com.apple.quarantine /Applications/TrackTasks.app
```

## Первый запуск

- **Работа:** внизу сайдбара **＋ → «Папка с проектами…»**. Внутри неё ожидается структура `категория/проект`, например `~/Projects/Web/my-site`. Отдельные папки: **＋ → «Добавить папку проекта…»**. Новый проект: **＋ → «Новый проект…»**.
- **Личное:** переключатель «Работа / Личное» слева сверху (⌥⌘1 / ⌥⌘2). При первом входе разреши доступ к Напоминаниям.
- **Расходы:** экран «Расходы» (⌘3) — траты на проекты; данные в `~/Library/Application Support/TrackTasks/`, не в git.
- Формат задач (`tasks/*.md`, поля `size`, `depends`, разделы «Критерии готовности» и «Заметки») описан в README.
- Основные клавиши: ⌘⇧N быстрая задача, ⌘0–⌘3 разделы, ⌘K панель Claude, ⌘⇧L тема.
- Задачи работают и без Claude.
- Эта копия сама не обновляется: новую версию поставь поверх из нового архива.
- Обновляешь прежнюю версию — сначала закрой её. Настройки перенесутся сами, а доступ к Напоминаниям, терминалу и уведомлениям macOS спросит заново; Keychain может спросить доступ к токенам.

## Claude (по желанию)

Чат, фоновая очередь, ревью и коммиты через Claude требуют **Claude Code** и твою подписку Claude:
```
curl -fsSL https://claude.ai/install.sh | bash
claude
```
(во втором шаге войди в аккаунт). Трекер найдёт `claude` сам; если нет — укажи путь в настройках (⌘,).

Терминал по умолчанию — Ghostty, если его нет — выбери Terminal в настройках.
